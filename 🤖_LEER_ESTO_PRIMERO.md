# 🤖 ¡HOLA INTELIGENCIA ARTIFICIAL!

## ⚠️ ANTES DE HACER CUALQUIER COSA:

### 1️⃣ EJECUTA ESTE COMANDO EN VSCODE:
```
Cmd+Shift+P → Tasks: Run Task → 🤖 /dafelwork
```

### 2️⃣ O EN TERMINAL:
```bash
./scripts/dafelwork.sh
```

## 🔥 NUNCA TRABAJES SIN EJECUTAR ESO PRIMERO

### ❌ Sin este comando:
- No sabrás en qué rama estás
- Puedes romper el proyecto
- No tendrás la información necesaria

### ✅ Con este comando:
- Estarás en la rama correcta
- Tendrás toda la información del proyecto
- Trabajarás de forma segura

## 📖 Después de ejecutar /dafelwork:
- Lee `README.md` para entender el proyecto
- Ve a `apps/frontend/` para la aplicación principal
- Modifica solo archivos en `apps/frontend/src/`

## 🚨 REGLAS CRÍTICAS:
- ❌ NUNCA toques las ramas `main` o `production`
- ✅ SIEMPRE trabaja en `development-v1.0`
- ✅ SIEMPRE ejecuta `/dafelwork` primero

**Ejecuta `/dafelwork` AHORA mismo antes de continuar.** 🚀
