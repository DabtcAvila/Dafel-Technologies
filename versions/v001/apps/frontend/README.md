# 🚀 DAFEL FRONTEND - APLICACIÓN PRINCIPAL

## ⚡ Inicio Rápido

```bash
# 1. Instalar dependencias
npm install

# 2. Ejecutar en desarrollo
npm run dev

# 3. Abrir en navegador
http://localhost:3000
```

## 📁 Archivos Importantes

- `src/app/page.tsx` - Página principal
- `src/app/hub/page.tsx` - Sistema hub
- `src/components/` - Componentes UI
- `package.json` - Configuración del proyecto
- `.env` - Variables de entorno (NO commitear)

## 🔧 Comandos

```bash
npm run dev          # Desarrollo
npm run build        # Build producción
npm run test         # Ejecutar tests
npm run lint         # Verificar código
npm run type-check   # Verificar TypeScript
```

## ⚠️ Importante

- **Siempre** ejecuta `/dafelwork` desde la raíz del proyecto antes de trabajar
- **NO** toques las ramas `main` o `production`
- **SOLO** trabaja en `development-v1.0`

## 🎯 Tecnologías

- **Next.js 14** - Framework React
- **TypeScript** - Tipado estático
- **TailwindCSS** - Estilos
- **PostgreSQL + Prisma** - Base de datos
- **NextAuth.js** - Autenticación
