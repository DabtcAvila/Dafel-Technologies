## Quick Start

```bash
git clone https://github.com/DabtcAvila/Dafel-Technologies.git
cd Dafel-Technologies/frontend
npm install
npm run dev
```

## Architecture

The platform is built with a modern Next.js architecture:

- **Frontend**: Located in `/frontend/` directory
- **Database**: PostgreSQL with Prisma ORM
- **Security**: AES-256-GCM encryption for credentials
- **Monitoring**: Winston logging + Prometheus metrics
- **Authentication**: NextAuth.js with role-based access control
